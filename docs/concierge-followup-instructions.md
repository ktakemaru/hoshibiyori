## 6. 第 3 部: 夜に見られるものを JSON に出す(提案 2)

`git switch -c feature/json-highlights`(第 2 部の上)。

- `--json-out` に、夜ごとの見どころを足す。置き場は、`scanned_nights[]` と `requested_nights[]` の両方から引ける形にする(同じ中身を 2 回持たない作りを選ぶ)。
- 中身は、**レポートの「この時期の見どころ」(`sky_highlights.py`)が出しているのと同じ値を、文でなく値として**。計算を新しく作らず、同じ関数の結果を使う。
  - 時間帯(宵・夜半・明け方と、その始まり・終わり)、対象の ID・名前・種類(惑星・星座・星団・流星群 など)、見える時間帯、最大高度とその時刻、月が出ているか。
  - 流星群: 極大の日、放射点が高い時間帯、出現数の目安があればその値と「例年の目安」であること。
  - `basis`: 何を基準にした目安か(基準の地点・平らな地平線。地形・雲を見ていない)。コンシェルがそのまま文に使える短い語にする。
  - 見えない対象(今の時期の銀河中心など)は、見えないと分かる形で入れる(省かない)。
- レポートに出ない夜(暗い時間帯が無い夜など)は `null`。値が無い項目は `null`(0 や推測で埋めない)。
- **星の座標のうち、星表と照合していないもの(`targets.json` に足した 19 件)が含まれるなら、その対象に「未照合」と分かる印を付ける。**
- 探索・順位・スコアには使わない。通信は増やさない。計算の時間が増えるなら、秒を測って報告書に書く(`--json-out` を付けないときは計算しない)。
- スキーマ・テスト(レポートの見どころと JSON の値が同じ対象・同じ時刻になること)・`AGENTS.md`・`README.md`・`CHANGELOG.md` を合わせる。
