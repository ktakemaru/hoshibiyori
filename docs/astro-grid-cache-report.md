## 5. 言えること・言えないこと

言えること:
- 薄明の時刻のずれは、全897地点 × 6夜で最大 0.61 分。
- 主要146件の固定キャッシュでは、候補の顔ぶれ・上位20件は変わらない。変わるのは時刻の表示(1分未満)と、stars の僅差の順位。

- 保存済みのとき、主要146件の stars は約3秒(固定キャッシュ・通信なし)。

言えないこと:
- 無月時間帯の15分のずれ(0.22%)が、別の夜・別の月齢でどれだけ出るか(今回の6夜だけ)。満月前後の月の出入りが夜の中にかかる時期は増える可能性がある。
- 全897地点での `explore` の時間(本人が下の6章で確かめる)。
- `generate_report.py` の通しの実行(配線は単体テストのみ)。
- 他の日付の固定キャッシュで、候補の顔ぶれが変わらないか(今回の1つのキャッシュだけ)。僅差の地点が閾値の境目にいれば、晴れ間の1分未満の違いで出入りしうる。
