「この時期の見どころ」を広げ、長い作業の前に時間の目安を伝えるようにした版です。

## 新しくできること

- **「この時期の見どころ」が広がりました**: 宵・夜半・明け方ごとの惑星(金星・火星・木星・土星)と季節の星座・星団・銀河、30日以内に極大がある流星群、冬の天の川の帯を、レポートに出します。今は見えない対象は、次に見える月とともに出します。
- **長い作業の前に、時間の目安を伝えます**: 探索・レポートの生成の始まりに1行出ます。`--estimate` を付けると、通信も計算もせずに見積もりだけを出します。
- **星空・星座モード(`--target stars`)の情報**: 予報の端の印(「ECMWFだけの予報(目安)」。天の川モードにも付きます)、空の開け具合(地形のデータがある88地点)、冬の天の川の帯。どれも順位には使っていません。
- **探索結果の JSON 出力(`--json-out`)** と、**聞かれた夜を調べる `--nights`**: ほかのプログラムが探索結果を読めます。`--nights` は、月の条件で候補に入らない夜も、通信を増やさずに調べます。地点は変わらない ID(`site_id`)で見分けられます。

## 結果が変わる変更

- **天の川モードで、地形データの無い地点を地平線 0°(水平)として判定します。** これまでは銀河中心の高度を見ずに「見える」扱いだったため、銀河中心が夜のあいだ地平線の下にある時期(晩秋〜冬)にも候補に残っていました。対象は897地点のうち地形データの無い809地点です。星空・星座モードと、地形データのある地点は変わりません。

## 直したもの

- 星空・星座モードの一覧の見出しが、天の川モードの文のままだった
- `report_courses.py`・`weekend_page.py` が、星空・星座モードのレポートを読めなかった
- 標高の無い地点(石廊崎・ヘブンスそのはら)で、星空ガイドの `--spot` が落ちた
- 「うち地形データなし」の件数が、通過した件数より大きく出る日があった(表示だけ)

## 変えていないこと

スコア式、雲量・光害などの閾値、光害の判定、雲量の判定の仕方は、1.1.0 と同じです。

## 注意

- 見どころは、基準の地点・平らな地平線の目安です。地形と雲は見ていません。
- 星・星団の座標は、星表と照らしていない目安です(流星群の表は 2026-11-24 に照合済み)。
- 流星群の出現数は理想の条件での目安で、実際に見える数はこれより少なくなります。突発的な増減は予測できません。
- 光害の指数(ALR)は、日本で未較正の相対指数です。
